### مرحباً بك في حسابي! 👋

أنا **أسامة العمري**، مهندس تقني ومطور ويب متكامل (**Full-Stack Developer**) متخصص في بناء تطبيقات ويب وتطبيقات الهواتف الذكية عالية الأداء، مع خبرة متقدمة في إدارة القواعد، تطوير واجهات برمجة التطبيقات (RESTful APIs)، وتصميم بوابات شبكات الواي فاي.

---

### 🛠️ التقنيات واللغات البرمجية:
* **Front-End & UI/UX:** HTML5, CSS3, JavaScript, Responsive Web Design
* **Back-End:** PHP, Python (FastAPI), RESTful APIs & API Integration, SQL, MySQL (XAMPP Server)
* **Mobile & Cross-Platform:** Flutter, Dart
* **Specializations:** Hotspot & WiFi Captive Portal Design
* **Tools & Environment:** Visual Studio Code, XAMPP, Git, GitHub

---

### 🚀 نبذة عن أعمالي:
* بناء وتطوير تطبيقات الهواتف الذكية عبر منصات متعددة باستخدام **Flutter و Dart**.
* تصميم وتطوير واجهات وبوابات تفاعلية ومميزة لشبكات الواي فاي اللاسلكية (WiFi Captive Portals).
* تطوير منصات تفاعلية ومواقع ويب مخصصة ومتكاملة مع لوحات تحكم إدارة متقدمة.
* بناء وتطوير خدمات الويب وRESTful APIs وربط التطبيقات والأنظمة بكفاءة عالية.
* تصميم قواعد بيانات مرنة وآمنة باستخدام MySQL عبر بيئة تطوير XAMPP وإدارة الاتصالات عبر PHP PDO.
